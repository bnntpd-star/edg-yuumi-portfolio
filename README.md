## 🚀 How to Deploy on GitHub Pages (2 Easy Methods)

### Method 1: Upload via GitHub Website (Fastest — 1 Minute, No Git Install Needed)

1. Go to [GitHub](https://github.com) and click **New Repository**.
2. Name your repository (e.g. `edg-yuumi-portfolio` or `username.github.io`).
3. Set visibility to **Public** and click **Create repository**.
4. On the setup screen, click **"uploading an existing file"**.
5. Drag and drop all files from this folder (`index.html`, `style.css`, `app.js`, and the `assets/` folder) into GitHub, then click **Commit changes**.
6. Go to **Settings** > **Pages** (in the left sidebar).
7. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` (or `master`) and `/ (root)` folder
   - Click **Save**.
8. Within 1-2 minutes, your portfolio will be live at:
   `https://<your-username>.github.io/<repository-name>/`

---

### Method 2: Deploy Using Git CLI

```bash
git init
git add .
git commit -m "Initial commit: EDG Yuumi portfolio"
git branch -M main
git remote add origin https://github.com/<your-username>/<repository-name>.git
git push -u origin main
```
Then enable GitHub Pages in **Settings** > **Pages**.
